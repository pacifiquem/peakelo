# `/roadmap`, `/drills`, `/drills/[id]` — syllabus and practice

Training surfaces. Always in the rail. Analysis-plan players see the truth and a Training CTA —
we do not hide the product.

## `/roadmap`

Ordered path from this profile toward what a stable player at the next band already does.
The path is names and a count. The explanation opens with the step. See
[`docs/design/learning-path.md`](../design/learning-path.md). Not XP, and not a cartoon trail.

### On the desk now

Empty syllabus plate. No canned “Beginner → Master” tree.

### Later

Steps from the product def only:

- Blunder-preventer
- Replay own mistakes
- Defend worse
- Convert advantage
- Make a plan (intermediate+)

Each step comes from a `now[]` action on the writeup — one per named leak, not a fixed three.
Skill, why (a profile sentence), evidence games, drill ids, done-when that is behavioral
(“you stop hanging the English bishop to …Bh3 in the next 15 White games”), not XP.
Current step gets the one gold rule. In-page `#s3`, no `/roadmap/[step]`.

Empty without a profile: “A roadmap without a profile is a generic tactics book. Wait for the
writeup.”

## `/drills`

Assigned queue from the roadmap (and from “Drill this” on a game). Not Puzzle Storm.

### On the desk now

Empty queue plate.

### Later

`/drills` is a **set index**: one card per drill kind (Blunder-preventer, Replay the miss, …),
not a list of every position. Click a set → `/drills/blunder-preventer` (kind slug) for the
moments from their games, then `/drills/[id]` to replay one. Due / done lives on the set page.
Progress is live from stored attempts: each set and each syllabus step shows cleared / total
positions. Hitting a drill marks it done and it stays on the Done list with the time it was
cleared. Roadmap steps link to that ledger. Not XP.

No drill until the roadmap names a leak.

## `/drills/[id]`

One position, one job, the student moves.

### On the desk now

Do not open a playable board. “This drill has no position yet. We will not put a textbook mate
in front of you and call it yours.”

### Later

Stem (why you). Board. On miss: the idea in words + the refutation arrow, not “−2.4.” On hit:
what to notice next time. Try again / See the game (`/games/[id]?ply=`) / Next drill / Back to
step. Types: replay the mistake ply; defend a worse position from their loss; convert an
advantage they dumped; what’s the plan; blunder-preventer (hangs / last-move threat / 3–4 move
combo).
